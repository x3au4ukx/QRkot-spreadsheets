# Благотворительный фонд QRKot

## Описание

API-сервис для управления благотворительными проектами и пожертвованиями. 
Средства автоматически распределяются между открытыми проектами.

Дополнительный функционал — генерация Excel-отчётов с временем сбора средств 
по каждому проекту с автоматической загрузкой на Яндекс Диск и публикацией.

## Технологии

- Python 3.11
- FastAPI
- SQLAlchemy (Async)
- Pydantic
- SQLite (по умолчанию)
- XlsxWriter
- HTTPX
- Яндекс Диск API

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/x3au4ukx/QRkot-spreadsheets.git
cd QRkot-spreadsheets
```

### Настройка виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка .env

Создайте файл .env в корне проекта:

```env
app_title=Благотворительный фонд
description=Платформа для сбора средств
database_url=sqlite+aiosqlite:///./fastapi.db
secret=your_secret_key
first_superuser_email=admin@example.com
first_superuser_password=admin123
yandex_disk_token=ваш_токен_яндекс_диска
report_format=%Y.%m.%d %H:%M:%S
```

### Применение миграций

```bash
alembic upgrade head
```

### Запуск сервера

```bash
uvicorn app.main:app --reload
```

После запуска документация доступна по адресам:

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

## Эндпоинты

### Проекты (только для суперюзеров, кроме GET)

| Метод | Эндпоинт | Описание |
| ----- | -------- | -------- |
| POST | /charity_project/ | Создать новый проект |
| GET | /charity_project/ | Получить все проекты |
| PATCH | /charity_project/{id} | Обновить проект |
| DELETE | /charity_project/{id} | Удалить проект |

### Пожертвования

| Метод | Эндпоинт | Описание |
| ----- | -------- | -------- |
| POST | /donation/ | Создать пожертвование (для авторизованных) |
| GET | /donation/ | Получить все пожертвования (суперюзер) |
| GET | /donation/my | Получить свои пожертвования |

### Отчёты (только для суперюзеров)

| Метод | Эндпоинт | Описание |
| ----- | -------- | -------- |
| POST | /report/ | Создать Excel-отчёт и загрузить на Яндекс Диск |

### Пользователи (FastAPI Users)

| Метод | Эндпоинт | Описание |
| ----- | -------- | -------- |
| POST | /auth/jwt/login | Вход (JWT) |
| POST | /auth/register | Регистрация |
| GET | /users/me | Текущий пользователь |
| PATCH | /users/me | Обновить профиль |

## Логика инвестирования

1. **Создание проекта** — средства из доступных пожертвований автоматически
инвестируются в новый проект (FIFO).

2. **Создание пожертвования** — средства автоматически распределяются между
открытыми проектами (FIFO).

3. **Закрытие** — при достижении цели проект или пожертвование автоматически
закрывается (устанавливается close_date, fully_invested = True).

## Отчёты

Суперюзер может сгенерировать Excel-отчёт, который содержит:

- Название проекта

- Время сбора средств (от создания до закрытия)

- Описание проекта

Отчёт автоматически:

- Загружается на Яндекс Диск в папку Reports

- Публикуется (становится доступным по публичной ссылке)

Ссылка на скачивание возвращается в ответе на запрос.
